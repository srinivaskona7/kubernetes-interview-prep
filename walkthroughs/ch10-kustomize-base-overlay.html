What problem does Kustomize solve, and how do bases and overlays work?

Chapter 10 junior walkthrough · 4 steps
Say first

Kustomize manages per-environment differences without templates: you keep one base set of plain YAML and layer small overlays on top for dev, staging and production.

✓ Best troubleshooting path

  • Reproduce with the diagnostic command (step 1-2).
  • Hand-editing copies of manifests for each environment drifts apart and invites mistakes. Think of a master recipe with sticky-note tweaks per kitchen: the recipe is never rewritten.
  • The base holds the shared Deployment, Service and ConfigMap. Each overlay directory has a kustomization.yaml pointing at the base plus patches, such as a higher replica count or tighter limits for production.
  • Because it is built into kubectl, you can preview with kubectl kustomize and apply with kubectl apply -k, with no extra install and no templating language.
  • Apply the fix command (step 3), then verify (step 4).

Explain

  • Hand-editing copies of manifests for each environment drifts apart and invites mistakes. Think of a master recipe with sticky-note tweaks per kitchen: the recipe is never rewritten.
  • The base holds the shared Deployment, Service and ConfigMap. Each overlay directory has a kustomization.yaml pointing at the base plus patches, such as a higher replica count or tighter limits for production.
  • Because it is built into kubectl, you can preview with kubectl kustomize and apply with kubectl apply -k, with no extra install and no templating language.

Key points

  • Template-free and declarative
  • Patches are strategic merge or JSON patches
  • Generators create ConfigMaps and Secrets, adding a hash so changes trigger rollouts
  • Transformers add name prefixes or suffixes, labels and annotations to everything

Commands

CommandWhat it shows
kubectl kustomize overlays/prodRender the final manifests without applying
kubectl apply -k overlays/prodBuild and apply the production overlay
kubectl diff -k overlays/prodPreview what would change in the cluster
