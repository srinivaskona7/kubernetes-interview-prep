Explain

  • First the browser resolves the hostname. The answer is the address of the load balancer in front of the controller.
  • The controller picks the matching rule using host and path, and decrypts TLS if it is the termination point.
  • It reads the Service's endpoints through the API data it already watches and chooses a pod using its balancing algorithm.
  • The pod runs the application logic, perhaps calling a database or cache, and the response flows back through the controller to the client.

Key points

  • Five hops: DNS, load balancer, controller, pod, back
  • TLS usually terminates at the controller
  • Endpoint data is cached from watches
  • The same path in reverse carries the response
