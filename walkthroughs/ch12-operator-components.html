✓ Best troubleshooting path

  • Reproduce with the diagnostic command (step 1-2).
  • The controller is the brain: it watches CRs and drives the real world toward the declared state. Event handlers are its ears, reacting to create, update and delete events and queuing reconciliation work.
  • Client libraries such as client-go let the controller list, watch and modify objects. OLM is an optional manager that installs, upgrades and tracks Operators in a cluster.
  • The reconcile loop is a pattern, not a separate component. Operators also lean on RBAC, Jobs and other native features, and the developer decides how.
  • Apply the fix command (step 3), then verify (step 4).

Explain

  • The controller is the brain: it watches CRs and drives the real world toward the declared state. Event handlers are its ears, reacting to create, update and delete events and queuing reconciliation work.
  • Client libraries such as client-go let the controller list, watch and modify objects. OLM is an optional manager that installs, upgrades and tracks Operators in a cluster.
  • The reconcile loop is a pattern, not a separate component. Operators also lean on RBAC, Jobs and other native features, and the developer decides how.

Key points

  • Controller holds the lifecycle logic.
  • Event handlers trigger reconciliation from watch events.
  • client-go (or similar) talks to the API.
  • OLM handles packaging and upgrade of the Operator itself.
  • RBAC must grant the Operator only what it needs.
